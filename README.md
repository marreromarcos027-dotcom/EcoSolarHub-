# EcoSolarHub v5

Usuario de prueba: `admin`
Contraseña: `EcoSolarHub2026!`

Incluye portada visual, navegación, equipos, accesorios, servicios, proyectos, cantidades, administrador, edición de precios/fotos y generación real de prefactura PDF.

La administración de esta versión usa localStorage para pruebas. Para que los cambios sean globales se conectará después a Supabase Authentication, Database y Storage.

El PDF se genera y descarga en el dispositivo. El botón PDF + WhatsApp abre WhatsApp con el pedido; el adjunto automático del PDF requiere WhatsApp Business Cloud API.
